構成の説明

当事業者は自ら電気通信回線設備を設置せず、以下のクラウドサービスを利用してサービスを提供しています。

  • CDN / セキュリティ：Cloudflare, Inc. — DNS管理、CDN配信、DDoS対策、WAF（Webアプリケーションファイアウォール）
  • Webサーバー：Vercel, Inc. — Next.jsアプリケーションのサーバーレスホスティング
  • データベース：Supabase, Inc.（AWS東京リージョン上） — PostgreSQLによるデータ永続化
  • 認証：Google LLC — OAuth 2.0プロトコルによるユーザー認証（Googleアカウント連携）
  • 画像保存：Amazon Web Services, Inc. — S3オブジェクトストレージ
  • メール送信：Resend, Inc. — トランザクションメール（問い合わせ通知）

通信の保護

  • ユーザーとサーバー間の全ての通信はHTTPS（TLS 1.2以上）により暗号化
  • データベース接続はSSL暗号化通信を使用
  • 認証情報はOAuth 2.0 + PKCEプロトコルにより保護（パスワードの保存・中継なし）
  • セッション管理はJWT（署名付きトークン）による

提供するサービスの概要

  • サービス名：戯曲図書館（gikyokutosyokan.com）
  • 内容：演劇脚本の検索・レビュー・コメント機能、ユーザー間メッセージング機能（予定）、脚本売買仲介機能（予定）の提供
  • 利用者：演劇関係者および一般の演劇愛好家
  • 通信の媒介：コメント・レビュー投稿（不特定多数への情報発信）、ダイレクトメッセージ（特定者間通信、実装予定）
